Web de inmobiliaria con CRUD.

Objetivo y Funcionalidades

El objetivo es una web para la venta y alquiler de propiedades en mallorca para la inmobiliaria Inmogibert. Para ello no solo se muestran las viviendas de forma paginada con diversos filtros, sino que tambien cuenta con login a una zona de administrador. En esta zona de administrador se puede hacer CRUD completo de todas las propiedades, solo pro aquellos usuarios autorizados.

Tecnologías y Aprendizaje

Se hace uso de NextJs como framework,Tailwind como estilos, Leaftlet para mapas y firebase como base de datos. Este proyecto, ha sido un reto a la hora de integrar una api compleja en este proyecto de NextJs además de un frontend muy grande.
