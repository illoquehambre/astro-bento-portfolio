Clon de Spotify usando Astro y ReactJs

Objetivo y Funcionalidades

Proyecto basado en el Clon de spotify de Midudev. El objetivo de este proyecto es realiza un reproductor de musica web en el que crear listas de resproducción a partir de archivos de audio subidos por el usuario. Estas listas serán compartibles para la reproducción, no la descarga, por otros usuarios de la aplicacion..

Tecnologías y Aprendizaje

Este proyecto contiene un reproductor de musica como estado global usando zustand, el cual se mantine activo y editable a lo largo de toda la aplicación; Estilos generados con TailwindCSS; Componentes React & Svelte.
